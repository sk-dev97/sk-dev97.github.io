# Suresh Kumar — React Portfolio

A React portfolio built with Vite and published with GitHub Pages.

## Run locally

1. Install Node.js.
2. Run `npm ci`.
3. Run `npm run dev` and open the local URL Vite prints.

## Deploy

The GitHub Actions workflow builds and publishes the site on each push to `main`.

## Where to edit

- `src/components/` contains the page sections.
- `src/data/` contains profile, skills, and project details.
- `src/styles/` contains the layout, typography, motion, skill, and neon styles.
- `src/assets/` contains the replaceable placeholder images.
