# Suresh Kumar — React Portfolio

A React portfolio built with Vite.

## Run the portfolio

1. Open this folder in a terminal.
2. Run `npm install` the first time.
3. Run `npm run dev` and open the local address shown in the terminal.

Run `npm run build` to create a production version.

## Where to edit things

- `src/App.jsx` puts the page sections in order.
- `src/components/` contains the page sections and the smaller pieces they use.
- `src/data/` contains profile, skills, and project details.
- `src/styles/` keeps the base, text, motion, skill, and neon styles in separate CSS files.
- `src/assets/` contains local placeholder images. Replace `profile-placeholder.svg` when your portrait photo is ready.
- `src/hooks/` contains the theme and active navigation behavior.

The contact form opens a prefilled email in the visitor’s email app. It does not send email from a server.
